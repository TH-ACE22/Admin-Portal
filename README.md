# 🖥️ Lefatshe Larona Admin Portal

The **Lefatshe Larona Admin Portal** is a web-based management dashboard for government administrators and service providers within the **Lefatshe Larona Community Platform**.  
It enables officials to manage communities, publish verified announcements, review citizen reports, and moderate platform activity — bridging communication between the government and the public.

---

## 🚀 Overview

This portal serves as the **administrative interface** for the Lefatshe Larona ecosystem.  
Built with **React.js**, it connects seamlessly to the **Spring Boot backend** to manage users, channels, and announcements in real time.  
The portal supports secure login via **Keycloak** and integrates with **Cloudinary** for media management.
